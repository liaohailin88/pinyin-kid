# 拼音星球 🪐

给一年级小朋友的**语文基础练习网页**：拼音（认字母 / 拼读 / 声调）+ 认字 + 笔顺 + 朗读（课文跟读），
内容对齐**部编版（统编版）一年级上下册**。

- 纯静态网页，**不联网也能用**，双击 `index.html` 就能打开
- 手机 / 平板 / 电脑都能用，横竖屏自适应
- 没有登录、没有广告、没有家长报表，打开就是给孩子玩
- 进度只存在本机浏览器里，不上传任何服务器

---

## 一、怎么打开

### 方式 0：直接用网址（已部署，最方便）

**https://liaohailin88.github.io/pinyin-kid/**

手机、平板、电脑都不需要装任何东西，浏览器打开就能用；可以把网址在手机上「添加到主屏幕」，
图标点开就是全屏，像个 App。进过网之后浏览器会缓存资源，弱网也能打开。

> 托管在 GitHub Pages（仓库 `liaohailin88/pinyin-kid`，`main` 分支根目录）。
> 想更新线上内容：在本地改完 `git add -A; git commit -m "..."; git push`，
> GitHub 会在一两分钟内自动重新发布，网址不变。

### 方式 1：直接双击（不用网络）

双击 `index.html`，用 **Edge / Chrome** 打开即可。

> 首次进入「笔顺描红」时会自动加载一个 1.4 MB 的笔画数据文件（`data/hanzi-all.js`），
> 需要 1～2 秒，之后就一直存在浏览器缓存里。

### 方式 2：局域网给平板用（推荐）

在电脑上双击运行 `scripts/serve.ps1`，它会打印两个地址：

```
http://localhost:8000          ← 电脑自己用
http://192.168.x.x:8000        ← 平板 / 手机在同一 WiFi 下输入这个
```

平板上用浏览器打开后，可以「添加到主屏幕」，用起来就像个 App。

> 用 `serve.ps1` 的好处：笔顺数据按需加载（只下载用到的字），比双击打开更快；
> 并且可以用麦克风跟读打分（`file://` 下浏览器会禁用麦克风）。

## 二、十二个练习

| 模块 | 练什么 | 玩法 |
|---|---|---|
| 🗺️ 拼音地图 | 声母 / 韵母 / 整体认读全表 | 23 声母 + 36 韵母 + 16 整体认读，**点格子就用"例字"发音**（不是读字母） |
| 🗣️ 拼音教读 | 声母 / 韵母怎么念 + 一个字怎么拼 | 三个页签：**声母 23**、**韵母 24**、**拼一拼 30**。点字母 → 卡片放大字 + 呼读音 + 口诀 + 发音要领 + 例字，自动连读三遍；拼一拼演示 `b + a → bā → 八 → 八个`，四步逐个亮起来 |
| 🅰️ 声母认读 | 听音辨声母 | 播一个真实汉字的音 → 从 4 个声母里选出开头的那个（干扰项优先取 b/d、p/q、b/p、d/t、n/h 这些易混的） |
| 🔤 韵母认读 | 听音辨韵母 | 同上，选项是韵母，含 an/ang、in/ing 这些前后鼻音 |
| 🎯 整体认读 | 16 个整体认读音节 | 听字音 → 选出 zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying |
| 🧩 拼读推一推 | 拼读（两种方向交替） | ①`b + ān` → 选出 bān（拼）②听字音 → 选出它由哪两个音拼成（拆） |
| 🎵 声调小侦探 | 四声分辨 | 听一个字 → 选第几声；答对后显示字和拼音 |
| 🏮 认字卡 | 看字读拼音 | 按 17 个单元选课；显示大字 + 带声调拼音 + 声调色条 + 词语 + 记忆口诀 |
| ✍️ 笔顺描红 | 笔顺 / 田字格 | 田字格里看笔顺动画 → 用手指跟着写（写错的笔画会提示）→ 共几笔 |
| 📖 朗读小站 | 朗读 / 口头表达 | 33 个课本短句，逐字跟读高亮；支持"慢慢读"；可用麦克风给跟读打分 |
| 📚 课文朗读 | 读整篇课文 | 13 首课本古诗 + 33 个课文句子**逐句带拼音**，整篇连读会自动翻句、逐字高亮；「我的课文」把任意课文粘进来自动注音 |
| 🎪 每日挑战 | 综合 | 10 道混合题，星星 / 连胜 / 徽章 |

**关键设计：所有听音题在作答前都不显示答案**——卡片上只有一个 🔊，
语音读的是**真实汉字的读音**（比如读"爸"而不是读字母 b），
因为大部分系统的中文 TTS 会把 `b` 读成英文的 "bee"。答对之后卡片才翻成"字 + 拼音"。

### 拼音教读（声母 / 韵母 / 拼一拼）

「🗣️ 拼音教读」是**只教不考**的一页，三个页签：

| 页签 | 内容 | 点一下会怎样 |
|---|---|---|
| 声母 23 | `b` 到 `w` | 卡片放大字母 + 呼读音（b 读「玻」= bo）+ 口诀（"右下半圆 b b b"）+ 发音要领（口型、送气）+ 3 个例字，自动连读三遍 |
| 韵母 24 | 教材那 24 个（6 单韵母 + 8 复韵母 + 1 特殊 `er` + 5 前鼻 + 4 后鼻） | 同上，另外标出"单独成音节时怎么写"（如 `üe` → `yue`） |
| 拼一拼 30 | 30 个一年级常用字 | 演示 `b + a → bā → 八 → 八个`：先读声母（玻），再读韵母（啊），再连起来是这个字，最后读词语，四个格子依次亮起来 |

这一页**不用设备自带的朗读**，用的是随程序打包的 107 段录音（`assets/voice/`）：
声音来自微软的神经网络语音，**离线可用，手机 / 平板 / 电脑听到的完全一样**，
不会出现"这台电脑一个口音、那台平板另一个口音"。

为什么必须有录音：系统读不出单独的 `b`，喂「b」它会念成英文 "bee"。所以按小学的做法
**用呼读音的汉字去读**（b 读「玻」＝bo，eng 读「鞥」）——这一套汉字和录音是提前生成好的。
口诀 / 要领来自 `js/pinyin.js` 里的 `INITIALS`、`FINALS`；拼一拼的 30 组在
`js/app.js` 的 `BLEND` 里，`scripts/probe.js` 会核对每条的拼音与生字库是否一致。

### 内置语音是怎么生成的

`scripts/gen_voice.py` 用 [edge-tts](https://github.com/rany2/edge-tts) 把 107 条内容 ×
3 个音色 = 321 个 MP3 一次性生成好，顺手做了**去掉首尾静音 + 音量归一 + 32kbps 单声道**，
总共只有 1.1 MB，整套网站一起拷走也不心疼：

```powershell
pip install edge-tts miniaudio lameenc
$env:HTTPS_PROXY='http://127.0.0.1:7890'    # 大陆网络需要
python scripts/gen_voice.py                 # 只补缺失的
python scripts/gen_voice.py --force         # 全部重做
python scripts/check_voice.py               # 检查有没有读歪的（见下）
```

| 音色 | 微软语音 | 语速 |
|---|---|---|
| 👩 女声 | `zh-CN-XiaoxiaoNeural`（晓晓） | `-6%` |
| 👨 男声 | `zh-CN-YunyangNeural`（云扬，主播腔） | `-18%` |
| 🧒 童声 | `zh-CN-YunxiaNeural`（云夏，少年音） | `-10%` |

`check_voice.py` 是个**不用联网、不用语音识别**的自检：同一个字三个音色读出来应该差不多长，
某一条比别的音色长/短一大截，就说明它没按字读（被念成字母、或者拆成几个音）。
云希 `zh-CN-YunxiNeural` 就是因为把 **鹅 / 恩 / 鞥** 念成了两秒多，被这个检查抓出来换掉的。

### 声音角色（女声 / 男声 / 童声）

在「⚙️ 设置 → 声音角色」里点一下就能换，点完立刻用新声音读一句给你听：

| 选项 | 听感 | 实际用的是 |
|---|---|---|
| 👩 女声 | 温柔的老师（默认） | 教读：晓晓；其它页面：`Huihui` / `Xiaoxiao` 这类女声 |
| 👨 男声 | 低沉的爸爸声 | 教读：云扬；其它页面：`Kangkang` / `Yunyang` 这类男声，没有男声时用女声压低音调模拟 |
| 🧒 童声 | 尖细的小伙伴 | 教读：云夏；其它页面系统里基本没有真童声，**把女声音调调高约 1.4 倍、语速乘 0.95** 模拟出来 |

下面「发音人」会列出这台设备上**所有中文语音**，可以手动指定（比如 Edge 的
`Xiaoxiao Online (Natural)` 听起来最自然）；选「自动」就按音色自己挑，**有网时优先用
`Natural` / `Online` 的神经语音**（好听得多），没网或用不上时退回本地发音人；
万一线上的语音一直不开口，1.6 秒后会自动改用本地发音人重读一遍。
当前实际在用谁、是不是模拟的，都会写在同一行小字里。设置存在本机，换设备要重新选。

> 📌 「拼音教读」不受上面这些影响——它有自己的录音，换音色就是换整套录音。

### 星星和徽章

- 答对 1 题 = 1 颗星；连续答对有"连胜"加成
- 每个知识点按**间隔复习**分级（Leitner 盒子 1→5），复习到第 4 级就算「掌握」，地图上会亮起来
- 「每日挑战」里答错过的知识点会被优先再考（`Store.needReview`）
- 11 个徽章：启程星（第一次答对）/ 十连对 / 二十连对 / 拼音小达人 / 声调小侦探 /
  朗读小百灵（朗读 10 句）/ 课文小喇叭（完整朗读 5 篇）/ 写字小书法家 / 识字半百 / 识字两百 / 百星王者
- 朗读一篇课文（「课文朗读」里整篇连读读完）一次 +3 星；跟读打分「很棒」再 +2 星

## 四、数据是怎么来的（请认真看这一段）

生字库共 **647 字 / 17 个单元 / 290 个"必写字"**，来源分几类，可靠性不一样：

| 范围 | 进入本库 | 来源 | 可靠性 |
|---|---|---|---|
| 一年级上册《写字表》 | 92 字 | 官方写字表，按单元分部 | ✅ 逐字核对（官方 100 字，剩余 8 字未取得原文） |
| 一年级下册《写字表》 | 198 字 | 官方写字表，按课序 | ✅ 逐字核对 |
| 一年级下册《识字表》 | 400 字按课分组 | 官方识字表按课分组原文 | ✅ 逐字核对 |
| 一年级上册课文生字 | 247 字 | 按官方目录**逐课重建** | ⚠️ 分课与顺序可能有出入 |
| `s1extra` 常用补充 | 37 字 | 一上《识字表》300 字的**官方完整清单没拿到公开原文**，这里是语文园地 + 一年级高频常用字 | ⚠️ **不是课文生字** |
| `wx` 写字表补充 | 12 字 | 下册《写字表》里有、但课文生字清单没覆盖到（如"医、哥、草"） | ⚠️ **不是课文生字** |

几项说明：

- 上表各行的字有重叠，**去重后 647 字**；上下册不重复分配（一个字只归属第一次出现的单元）。
- **一下的《识字表》400 字和《写字表》200 字是最可信的**；一上有 37 个字是"补充常用字"。
- 进「认字卡」时，单元列表里 `s1extra` 的标题是「一年级上册 · 常用补充」，
  `wx` 是「一年级下册 · 写字表补充」，都不会冒充课文生字。
- 官方《写字表》上册 100 + 下册 200 = 300 字。本库能落地的必写字是 **290 个**：
  上册原文只拿到 **92 / 100**，下册 **198 / 200**，两册之间没有重复。
  缺的 10 个字不在「笔顺描红」的必写字池里；把原文补进 `S1_WRITE` / `S2_WRITE` 后重跑脚本即可补上。

每个字的字段：

```js
{ c: '天', p: 'tiān', t: 1, sb: 'tian',   // 字 / 带调拼音 / 声调 / 不带调音节
  w: '天空', u: 's1u1', l: '天地人',        // 词语 / 单元 / 课
  w100: false,                            // 是否属于"必写字"
  m: '大字上面一横就是"天"' }              // 记忆口诀（部分字有）
```

拼音部分（23 声母 / 36 韵母 / 16 整体认读 / 标调规则）全部写死在 `js/pinyin.js` 里，
是标准《汉语拼音方案》的内容，不存在"猜"的成分。

笔顺数据来自开源项目 [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data)（MIT / Make Me a Hanzi），
已全部本地化，运行时**不请求任何外部网络**。

### 课文朗读的数据与版权（请认真看这一段）

「📚 课文朗读」里放了三类内容，边界是刻意划清楚的：

| 内容 | 数量 | 为什么能放 |
|---|---|---|
| 古诗（咏鹅 / 江南 / 画 / 悯农 / 古朗月行 / 风 / 春晓 / 赠汪伦 / 静夜思 / 寻隐者不遇 / 池上 / 小池 / 画鸡） | 13 首 55 句 | 唐宋明作品，**早已进入公有领域**，可以放全文 |
| 课本短句 | 33 句 | 就是「朗读小站」已有的那些短句，按单元分组，属于少量引用 |
| 我的课文 | 你自己粘贴 | 由使用者自己提供，程序只做注音和朗读；粘过的会存在本机，下次点「上次粘的课文」就能接着读 |

**现代课文（《小小的船》《雪地里的小画家》《四季》……）的全文没有内置**——
这些作品仍在版权保护期内，本仓库是公开仓库，整篇复制不合适。
想读整篇课文，请在「我的课文」里把文字粘进去（或用手机拍下课本后照着打几行），
程序会用 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)（MIT，已本地化到 `assets/pinyin-pro.min.js`）**逐字自动注音**，
再逐句连读、高亮、跟读打分。多音字（长/乐/行/藏…）能按词语上下文判断。

古诗的逐字注音是在**编译期**生成并写死的（`scripts/gen_texts.js`），
另有一张人工校正表处理多音字（曲 qū、冠 guān、露 lù、藏 cáng、行 xíng、斜 xié），
所以离线状态下课本古诗的拼音也是准的。

## 五、想改内容？

### 换生字 / 加单元

编辑 `scripts/gen_chars.py` 里的 `LESSON_PLAN`（课 → 字表）和 `S1_WRITE` / `S2_WRITE`（必写字集合），然后：

```powershell
# 需要先在本地装好 hanzi-writer-data
$env:HANZI_SRC = "$env:TEMP\pinyintest\node_modules\hanzi-writer-data"
$env:PYTHONIOENCODING = 'utf-8'
python scripts/gen_chars.py
```

会重新生成 `data/characters.js`、`data/hanzi-all.js` 和 `assets/hanzi/*.json`。

### 加古诗 / 改课文句子

编辑 `scripts/gen_texts.js` 顶部的 `POEMS`（标题 / 朝代 / 作者 / 每句原文），需要的话把多音字加进 `POEM_FIX`，然后：

```powershell
node scripts/gen_texts.js     # 重新生成 data/texts.js（逐字注音）
```

课文句子 tab 的 33 句来自 `data/characters.js` 的 `sentences`，改了那边重跑 `gen_chars.py` 再跑 `gen_texts.js` 即可。

### 改题目

出题器都在 `js/app.js` 里，一个函数一道题，返回结构固定：

```js
{
  key: 'pyi:b',            // 进度统计用的唯一键
  prompt: '题干',
  card: { glyph:'🔊' } 或 { zi:'天', sub:'天空', toneN:1 },   // 卡片
  speak: fn, autoSpeak: true,   // 语音
  opts: [{ v:'b', label:'b' }], // 选项（v 与 answer 比较）
  answer: 'b',
```

## 七、已知限制

1. **大部分页面的发音依赖系统的中文语音包**。Windows 自带"Microsoft Huihui / Yaoyao / Xiaoxiao"，
   Edge 里音质更好；某些精简版系统没有中文语音，此时音频类练习会没有声音
   （设置页有「语音检查」，会明确告诉你有没有找到中文语音）。
   **例外是「拼音教读」**——它用的是随程序打包的录音，不依赖系统语音包，离线也有声音。
2. **童声 / 男声是"调出来"的**：系统里通常只有女声，程序靠调整音调（和童声的语速）
   来模拟；部分在线神经语音会忽略音调参数，那时男女声听起来差别很小——换成设备上的本地语音
   （名字里没有 `Online` 的）差别就明显了。（教读页不用这套模拟，三个音色都是真人的神经网络录音。）
3. **跟读打分**用的是浏览器的语音识别（Chrome / Edge），需要联网、需要 https 或 localhost，
   识别不准时只当参考，不要当考试。
4. 拼音的**四声**由 TTS 读整字来体现，个别字的多音 / 轻声 TTS 可能读得不够准。
5. 一上有 37 个字是补充常用字（见「数据是怎么来的」），不是课文生字。
6. 没有做云端同步，换个浏览器进度就没了。
7. 「课文朗读」里**没有内置现代课文的全文**（版权原因），请用「我的课文」粘贴；
   粘贴的内容只存在本机浏览器里，不会上传。自动注音对生僻字 / 文言同音字偶尔会读错，
   家长陪读时听一遍就能发现。
8. 没有中文语音包时，「整篇连读」不会出声，但会像卡拉 OK 一样逐字高亮走一遍（进度照样算）。
   想看有没有语音：右上角「⚙️设置 → 语音检查」。
9. 「拼音教读」读的是**呼读音**（b 读"玻"= bo、n 读"讷"、eng 读"鞥"），这是小学课堂上教的读法；
   有几个只能"取最接近的字"来读：`ong` 用「嗡」、`ang` 用「昂」，听起来会比标准呼读音圆一点；
   单个声母 / 韵母没有声调，录音里是平读（一声的感觉），这是正常的。
   内置录音是**按字面生成的，没有用语音识别逐条复核**——`scripts/check_voice.py` 只能
   保证三个音色之间互相对得上（谁读得离谱会被抓出来），听感上的细节仍建议家长先自己听一遍。
